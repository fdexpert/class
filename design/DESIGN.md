# 紙與墨 — class 站設計規範 v1.2

2026-09-18 建立。這份規範定義 `class` 站所有頁面共用的視覺與行為語言。
**新頁面請先讀 [`AI-BRIEF.md`](AI-BRIEF.md)**，那是一頁版、可直接貼給任何 AI 工具的指令。

## 1. 為什麼是「紙」

這個站放的是課程手冊與教材，使用者會**長時間閱讀**，而不是操作介面。所以設計語言取自印刷品而非軟體：米紙底、墨色字、襯線標題、近乎方正的邊角、沒有陰影與漸層。層次只靠底色深淺與 1px 細線區分。

這套語彙源自雙語課程手冊原有的設計，現在提升為全站標準。

## 2. 兩個模式，同一張紙

| | 日間 | 夜間 |
|---|---|---|
| 概念 | 日光下的紙 | 檯燈下的紙 |
| 底色 | `#f7f5ee` 米紙 | `#171d1a` 暖墨 |
| 文字 | `#253d36` 墨綠 | `#e8e4d8` 暖白 |
| 連結 | `#14584a` 深墨綠 | `#7fc3a8` 亮青綠 |
| 金色 | `#b19b62`（兩模式相同） | 同左 |

金色兩個模式共用，是整套系統的錨點。

## 3. 色彩使用規則

- 頁面 CSS **不得出現任何 `#色碼`**，一律用語意變數。
- `--gold` 在米紙上對比僅 **2.49:1**，連 3:1 都不到，因此**只能用於裝飾**（`c-rule-gold` 細線、小圖飾）。任何承載資訊的金色用 `--gold-ink`（5.15:1）。
- `--line` 是裝飾分隔線；按鈕、輸入框等**互動元件的邊界**用 `--line-strong`（達 3:1）。
- 壓在第三方媒體上的顏色（影片縮圖的播放鍵黑白、YouTube 紅）是唯一允許硬寫色碼之處，因為它們不應隨主題改變。

所有色彩組合已於 2026-09-18 以程式驗證 WCAG 對比，數值記錄在 `tokens.json` 的 `contrast_verified`。

**一個實測得到的限制**：米紙上放不下比 `--muted` 更淡的第三層文字色——候選色全部低於 4.5:1。因此文字層級只有兩級（`--text`／`--muted`），更細的層次改用**字級與字重**表達，這也正是印刷品的做法。

## 4. 字體

| 用途 | 字體 | 說明 |
|---|---|---|
| 標題 | `--font-serif` Songti TC / Noto Serif TC | 印刷感的來源，只用於 h1–h3 |
| 內文與介面 | `--font-sans` PingFang TC | 螢幕上仍以無襯線最好讀 |
| 程式碼 | `--font-mono` | 教材大量使用 |

內文 16px／行高 1.8。**行高 1.8 是這套系統的特徵**，不要為了塞更多內容改成 1.5。

## 4.5 陰影：唯一的例外

紙的語言是無陰影的，但**浮動面板**（閱讀抽屜、手機側欄、彈窗）離開了桌面，需要深度提示。這類元件用 `--shadow-panel`，其餘一律不得有陰影，也不得自行寫 `box-shadow`。

## 5. 版面

- 長文閱讀頁：`--measure-read`（`min(46vw,640px)`）
- 站台頁：`--measure-ui`（820px）
- 間距一律取自 `--sp-1` 至 `--sp-8`（4/8/12/16/24/32/48/64），不要寫任意數值

## 6. 元件

`tokens.css` 已內建，直接套類別：

| 類別 | 用途 |
|---|---|
| `c-back` | 返回上一層。**非首頁必備** |
| `c-theme` | 主題切換鈕，需搭配 `data-theme-toggle` 屬性 |
| `c-card` | 卡片容器 |
| `c-tag` / `--on` / `--gold` | 標籤，`--on` 為進行中狀態 |
| `c-note` / `--warn` / `--gold` | 提示框 |
| `c-rule-gold` | 金色細飾線，唯一允許單用 `--gold` 之處 |
| `c-foot` | 頁尾 |

## 7. 主題行為

三態：`system`（預設，跟隨作業系統）／ `light` ／ `dark`，存於 `localStorage['class-theme']`，GitHub Pages 全站同源因此跨頁保持。切換鈕依序循環 system → light → dark。

**每頁 `<head>` 必須有防閃爍腳本且位於樣式之前**，否則換頁時會先閃一下前一個主題。主題邏輯一律使用 `design/theme.js`，不要自己寫。

## 8. CSS 架構

| 頁面類型 | 做法 |
|---|---|
| 站台頁（首頁、課程頁） | `<link rel="stylesheet" href="../design/tokens.css">` |
| 單檔教材、手冊 | 內嵌 `tokens.css` 全文，開頭標註 `/* tokens v1 — 由 design/tokens.json 產生，勿手改 */` |

內嵌是為了讓教材下載後離線開啟仍正常。代價是可能與來源漂移，因此**改完一定要跑 `node tools/check-design.mjs`**。

改 `tokens.css` 與 `tokens.json`（兩者要同步），提高版本號，重跑檢查腳本，然後把內嵌副本的頁面一併更新。不要只改單一頁面的顏色——那是漂移的開始。
